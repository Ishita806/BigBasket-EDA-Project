# BigBasket Product Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the BigBasket product dataset to understand product categories, pricing patterns, discounts, brands, and customer ratings.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Key Insights

* Beauty & Hygiene is the largest product category.
* Fresho is the most represented brand.
* Most products receive little or no discount.
* Kitchen, Garden & Pets has the highest average discount.
* Beverages has the highest average customer rating.
* Pricing anomalies were identified and removed during data cleaning.

## Dataset

BigBasket Products Dataset

* Exploratory Data Analysis
